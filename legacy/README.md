# The original master's project

`Projet_StarWars.ipynb` and `SynthetiqueProjet.ipynb` are the notebooks as they were
uploaded in January 2025. The rebuild in the parent directory reaches different
conclusions, and that comparison only means something if the starting point stays
readable.

One change was made: the printed output of the one cell that displayed lines of
screenplay dialogue was removed, because this repository does not redistribute the
scripts. The code is untouched, and so are all other outputs, including the 77%
accuracy report.

The table in the root `README.md` lists what changed in the rebuild and why.
